# Queendom Return

An *X4: Foundations* mod that unlocks the Kingdom End DLC sectors from the start

Copy `vukica_queendom_return/` into your X4 `extensions/` folder to install.

## Dependencies

| Dependency | DLC |
|------------|-----|
| `ego_dlc_boron`  | Kingdom End |
| `ego_dlc_terran` | Cradle of Humanity ||

## Changes the mod introduces

**Regions unlocked from the start.** The Boron DLC sectors no longer
sit behind their story plots — they are reachable immediately.

**A universal player HQ.** A player-owned headquarters is placed in Heretic's
End for all gamestarts (except Accomplished Scientist which retains vanilla
location in Grand Exchange.)

**Terran and Boron DLC start changes.**
- *Terran "Pioneers" (terran2):* stripped to a plain start — the 
  satellite-repair intro and the Pioneer HQ-acquisition mini-plot are removed.
- *Terran "Cadet" (terran1):* Pioneer HQ-acquisition mini-plot is removed.
- *Boron "Emergence" start:* removed and replaced with a new gamestart where
  player character is Nila Ti - Adventurer Extraordinaire.
- *Boron "Herald" starts:* since Herald missions are removed from the start, 
  alterations were made where player gets the Hydra Regal by default.

**Smaller tweaks.**
- Hydra Regal blueprint is now purchasable at Boron faction representative.
